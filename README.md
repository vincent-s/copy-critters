# Copy Critters

A memory sequence game for kids aged 6–10. Watch cute animals or colour blobs light up and make their sound, then tap them back in the same order. Each level adds one more step.

**Play it:** https://vincent-s.github.io/copy-critters/

## How to play

1. Pick **Animals** (meow, woof, moo, quack, ribbit, oink) or **Colours** (singing blobs).
2. Watch and listen as the critters light up one at a time.
3. Tap them in the same order. Keys 1–6 work too.

- Level 1 starts with 2 steps; each level adds one and plays a little faster.
- At level 5, two new critters join the board.
- You have 3 hearts, and win a bonus heart every 5 levels.

## Run locally

It's a single file with no build step. Open `index.html` in any modern browser.
